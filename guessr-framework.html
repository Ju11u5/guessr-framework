三分钟上手

  1. 上传数据：到「数据集」页，把表格粘进去（第一行是表头）或拖入 csv/json，点「解析并预览」。
  2. 调节规则：框架会自动推断每列的比较规则，你可以逐列改成想要的效果（很关键，见下表）。
  3. 开始玩：回「对局」页。本地出题=页面随机藏一个目标、自动给反馈，自己就能玩；外部裁判=你在别的地方（网站/群友出题）玩，把反馈手工录进来，它当你的参谋。

比较规则怎么选

规则绿的条件黄的条件适合
完全相同值一样不会黄名称、位置、状态、类别这类「对就是对」的列
文本宽松忽略大小写/空格/后缀后一样不会黄大小写不统一的昵称、符号
数值接近数值一样差值 ≤ 容差（并显示 ↑↓ 方向）年龄、身高、体重、数量、年份
同组即算接近值一样同属一组（需配「关联」指向分组映射表）国家→赛区、城市→省份、作品→作者
命中列表即算接近值一样该值出现在目标的另一个列表列里（需配「关联」指向那个列）当前队伍 vs 历史队伍、当前属性 vs 过往作品
集合有交集集合完全相同有任意一个共同元素标签、技能、配音演员

两个模式

猜名：一次猜一个目标，看各列反馈缩小范围。次数可自己定（默认 8 次）。

属性提问：像海龟汤一样问「他的某属性是某值吗」，回答只有 是 / 是也不是 / 不是，不给方向提示。提问数可自己定（默认 18 次）。

两种模式下右边都会实时给出建议：猜名给「最该猜谁」，提问给「最该问哪个属性的哪个值」，算法都是最小化期望剩余候选数。

数据格式

CSV / TSV（带表头）或 JSON 对象数组，一行 = 一个可猜的目标。数值列会自动识别成数字；用 / 或 , 分隔的多值会被识别成列表（配合「命中列表」规则用）。

例：
名称,队伍,历史队伍,国家/地区,年龄,位置,Major冠军,Major参赛,状态
选手甲,MOUZ,FaZe/NAVI,瑞典,25,狙击手,1,6,现役
